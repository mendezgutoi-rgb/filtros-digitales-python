# Implementación y Evaluación de Filtros Digitales

Repositorio correspondiente a la Actividad 3 de la materia. Este proyecto contiene la implementación en Python de filtros digitales de tipo Butterworth (pasa bajos, pasa altos y pasa bandas) utilizando las librerías SciPy, NumPy y Matplotlib para el procesamiento y análisis de una señal compuesta con ruido blanco gaussiano.
